# Axiom CMS — Frontend

> Modern, responsive frontend for Axiom CMS — a full-stack content management and blogging platform.

🌐 **Live Application:** https://axiom-cms.vercel.app

---

## 🛠️ Tech Stack

- **React** — UI development
- **React Router** — Client-side routing
- **TanStack Query** — Server-state management and API caching
- **Axios** — HTTP requests and API communication
- **React Hook Form** — Form handling and validation
- **Tailwind CSS** — Styling and responsive UI
- **GSAP** — Animations and page transitions

---

## ✨ Features

- 🔐 Authentication & protected routes
- 🔄 Access token + refresh token flow
- 👥 Role-based access control
- 📝 Create, edit, publish and manage posts
- 🏷️ Categories and tags
- 💬 Comments
- ❤️ Likes
- 👤 User profiles
- 🛡️ Admin dashboard
- 📄 Pagination, filtering and searching
- 📱 Responsive design
- 🎨 Modern editorial-style UI
- ⚡ API caching with TanStack Query
- 🎬 Smooth animations with GSAP
